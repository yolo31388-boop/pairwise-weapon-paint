# 武器涂装与自定义系统

## 项目描述

武器涂装与自定义系统的bug修复项目。核心模块 `ui/weapon_paint.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 涂装应用只设标志位不实际修改武器纹理
- 图案编辑器完全没做不能自定义图案
- 颜色选择器完全没做不能自定义颜色
- 涂装保存完全没做自定义涂装不持久化
- 涂装预览完全没做涂之前看不到效果
